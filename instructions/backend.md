# Бэкенд и экспорт

**Ветка `team/backend-api`.** Файлы `cmd/`, `internal/`, `batch/`. Изменения API и документации сверяем с фронтендом и извлечением.

1. Довести правку группировки до PR. Проверить пустой список, повторную загрузку одной публикации с DOI и без него, две разные публикации с совпадающими RAG-критериями и случай с разными протоколами.
2. Проверить одну реальную статью в режиме `python` по всей цепочке от `POST /documents` до семи CSV. Сверить сырое значение, нормализованную единицу, страницу и таблицу в API и выгрузке. Для baseline с неполными данными проверить пустой `baseline_value` и замечание со ссылками на обе записи.
3. До общего прогона повторить сценарий с `run --resume`. Убедиться, что пакетный запуск продолжает ждать сохранённые задания и выдаёт понятную ошибку при неоднозначном `corpus_id`.

**Готово, когда** проходят `go test ./...`, `go vet ./...` и `python3 -m unittest discover -s batch`, а в PR есть пример ответа API и проверенной CSV-строки.
