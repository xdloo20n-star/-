## Повторить обработку

Распакуйте архив участников в каталог `../corpus` рядом с репозиторием и запустите API в режиме Python с установленными Poppler и Tesseract:

```bash
EXTRACTION_MODE=python PYTHON_SCRIPT=extractor/main.py go run ./cmd/api
```

В другом терминале:

```bash
python3 -m batch run ../corpus/dev \
  --corpus-zip ../drive-download-20261120T125610Z-1-001.zip \
  --api-url http://127.0.0.1:8080 --timeout 3600 --output /tmp/sverka-dev

python3 -m batch.evaluate /tmp/sverka-dev \
  --corpus-zip ../drive-download-20261120T125610Z-1-001.zip
```

Путь к каталогу PDF зависит от того, куда распакован архив. Команда чекера организаторов и инструкции по проверке описаны в комплекте участников. Синтетические сканы требуют Tesseract и языкового пакета `eng`.
